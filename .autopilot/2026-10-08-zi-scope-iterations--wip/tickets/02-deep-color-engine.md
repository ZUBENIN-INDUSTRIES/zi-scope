## Что должно заработать

Обработка кадра умеет всё, что потом покажет окно «Глубокие настройки цвета»: усиление
каналов RGB, уровни (общие и по каналам), экспонирование, светлые, тени, белые и чёрные,
тональную кривую (общую и по каналам), HSL по 8 цветам, красочность, чёткость, удаление
дымки и резкость. Нейтральные значения не меняют ни пикселя. Превью остаётся плавным.
UI здесь не делается.

## Из брифа, дословно

> «Добавь ещё меню "глубокие настройки цвета", где добавь отдельно: RGB, узкие настройки фото как в лайтрум.»

## Разделы спецификации

Истории 23, 24, 25; Решения §4 (порядок конвейера); `interfaces.md` → модуль Imaging (точные типы).

## Критерии приёмки

- [ ] Типы `DeepColor`, `ChannelLevels`, `HslAdjust`, `ToneCurve`, `CurvePoint` — строго по `interfaces.md`; `ImageAdjustments.Deep` (по умолчанию `DeepColor.Neutral`); `IsIdentity` учитывает Deep; JSON-сериализация через существующий `SettingsStore` работает (round-trip `AppSettings` с ненулевым Deep — тест; старый JSON без `Deep` загружается в нейтраль — тест)
- [ ] `ImageProcessor.Apply` реализует порядок из Решений §4. Точечная часть идёт через LUT, где возможно; `ToneCurve.BuildLut` — монотонная гладкая интерполяция (например, монотонный кубический сплайн Фрича — Карлсона), концы клампятся, точки сортируются
- [ ] HSL: 8 секторов оттенка с плавными весами (без резких границ); сдвиг оттенка ±30° на +/−100; насыщенность и светлота сектора. Красочность (vibrance) сильнее поднимает малонасыщенные цвета, чем насыщенные
- [ ] Светлые, тени, белые, чёрные — тональные маски по яркости, плавные; без цветовых сдвигов на нейтральном сером
- [ ] Чёткость (локальный контраст по яркости, большой радиус), удаление дымки, резкость (unsharp mask, радиус 0.5–3 px). Считаются только при ненулевых значениях; сепарабельное размытие, параллельно по строкам, буферы переиспользуются (без 8 МБ аллокаций на кадр)
- [ ] Тесты (ожидания посчитаны вручную, не тем же кодом): нейтраль = побайтовое равенство; RedGain 2 удваивает R до клампа; уровни Black=50 переводят 50→0 и 255→255; кривая (0,0),(128,192),(255,255) поднимает середину; HSL синий Hue +100 смещает чистый синий к фиолетовому, не трогая красный; Highlights −100 уменьшает яркие и почти не трогает тёмные; Shadows +100 — наоборот; Vibrance поднимает насыщенность малонасыщенного сильнее; резкость увеличивает перепад на ступеньке; чёткость не меняет однотонный кадр
- [ ] Производительность: бенчмарк-тест или консольный замер (не входит в обычный прогон, можно `[Trait("Category","Perf")]` или Skip с инструкцией): кадр 1920×1440 со всеми включёнными настройками обрабатывается ≤ 100 мс на этой машине (≥ 10 к/с); результат замера — в CONCERNS
- [ ] `dotnet build`/`dotnet test` зелёные; существующие 117 тестов не сломаны
