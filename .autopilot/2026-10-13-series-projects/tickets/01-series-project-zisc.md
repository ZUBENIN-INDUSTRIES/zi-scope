## Что должно заработать

Лаборант начинает серию — в папке серии появляется `<имя серии>.zisc`, а у снимков серии больше нет .json. Метаданные всех кадров лежат в `.zisc` одним списком. Кнопка «Открыть проект серии…» открывает `.zisc` и продолжает серию с того же шага; при запуске программа предлагает продолжить незавершённую серию по её `.zisc`. Обычные снимки и их .json не меняются.

## Из брифа, дословно

> «мне не нравится json файл к каждому файлу в серии, надо это пофиксить. Ещё хочу чтобы были проекты серий. Чтобы я заходил в папку с серией, а там буде .zisc файл, и при открытие его можно было продолжить серию.»
> «1. в серии в .zisc одним списком 2. не трогай, там уже есть выключатель метаданных 3. через открыть проект серии, пока без реестров.»
> «в программе кнопка «Открыть проект серии…» продолжает серию с того же шага. Обычные снимки не трогать — у них свой выключатель метаданных. Ассоциацию .zisc в реестре Windows не делать.»
> «Забей, старые серии были только для тестов, в продакшене серии ещё небыли.»

## Критерии приёмки

- [ ] Снятый шаг серии (оба вида кадров) не оставляет в папке ни одного .json — при любом положении выключателя метаданных; `series.zscope-series.json` не создаётся
- [ ] После «Начать серию» в папке есть `<имя серии>.zisc` (недопустимые символы → `_`, пустое имя → `серия.zisc`), `"format": "zi-scope-series/2"`
- [ ] В `.zisc` список `Frames` — по записи на каждый файл снятых шагов (поля `FrameMetadata`, `File` — имя файла, `Extra` с группой/образцом/увеличением/видом); пересъёмка заменяет записи шага, «Удалить снимки» их убирает
- [ ] `SeriesStore.Load(путь .zisc)` поднимает план, текущий шаг, пересъёмку, статусы и метаданные; перенесённая папка открывается; переименованный проект сохраняется в тот же файл; битый/чужой/`/1` → `InvalidDataException`
- [ ] Кнопка «Открыть проект серии…» — диалог выбора файла `*.zisc`, серия продолжается с того же шага; ошибка → уведомление «Проект серии не открыт», состояние программы не меняется
- [ ] Новая серия в папке с `.zisc` — вопрос из spec R04.1; «Да» заменяет прежний проект, «Нет» ничего не меняет
- [ ] При запуске «Продолжить серию …?» работает по `.zisc` в последней папке серии (`FindProject`, самый свежий)
- [ ] Обычный снимок с включёнными метаданными пишет .json того же содержания, что и до правки (тест сравнивает имена полей); выключатель работает как прежде
- [ ] Никаких записей в реестр; тесты `SeriesStore`/`SeriesRunner`/`FrameExporter` переписаны под новый формат, весь набор зелёный; живая проверка в демо (копия из scratch, `--settings`): серия снята, `.zisc` открыт заново, продолжено
