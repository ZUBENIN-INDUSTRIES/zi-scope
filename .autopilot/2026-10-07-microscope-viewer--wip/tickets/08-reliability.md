## Условия (каждое — критерий приёмки)

**Хост и камера (`ViewModels/MainViewModel.cs`)**
- [ ] Закрытие окна никогда не ждёт поток камеры на UI-потоке без таймаута: закрытие камеры в Shutdown идёт через фоновую задачу с таймаутом (например 3 с), окно закрывается в любом случае
- [ ] Если окно закрыли, пока шло Open/Start камеры или демо, созданная камера после Shutdown закрывается (Dispose), а не устанавливается
- [ ] Обработчики событий камеры привязаны к экземпляру камеры (отписка не зависит от порядка Subscribe/Unsubscribe)
- [ ] Конвейер обработки не выделяет новый 8-МБ массив на каждый кадр: буферы переиспользуются (пул или ротация). Кадр, ушедший наружу (`LatestProcessedFrame`, `ProcessedFrameReady`), после этого не перезаписывается, пока на него может кто-то ссылаться: правило владения описать в INTERFACES
- [ ] `CompositionTarget.Rendering` подписан только пока идёт поток кадров (или пока есть что показывать)
- [ ] «Повторить» / «Переподключить» из демо-режима при отсутствии реальной камеры не гасит работающий демо-режим (показывает Notify «Камера не найдена»)
- [ ] `SaveSettingsSoon` не сериализует настройки на каждый вызов: дебаунс в хосте (сериализация не чаще раза в ~1 с), без потери последнего изменения
- [ ] После «Сбросить настройки» панели, которые кэшируют данные из настроек (пресеты в ColorPanel, список объективов в ScalePanel и др.), перечитывают их. Удалённые пресеты и объективы не возвращаются при следующем сохранении. Механизм — например событие хоста `SettingsReplaced`; описать в INTERFACES

**Диалоги**
- [ ] Один общий помощник `UI/Dialogs.cs` (например `Dialogs.ConfirmAsync(owner, title, text, primary, secondary?)`, `Dialogs.AskTextAsync(owner, title, label, initial)`, `Dialogs.InfoAsync`), который единообразно обрабатывает отсутствие `ContentDialogHost`. Все существующие копии (ColorPanel, ScalePanel, Gallery, DriverStartupFlow, где применимо) переведены на него

**Камера-панель (`CameraPanelViewModel`)**
- [ ] Автоэкспозиция не считает MeanLuma в потоке камеры (через Task.Run или по копии); ожидание кадра отменяется при приходе кадра и при `CameraChanged`; таймер ожидания не висит

**Драйверы (`Drivers/`)**
- [ ] По таймауту тихой установки процесс установщика завершается (Kill, с обработкой отказа доступа к повышенному процессу). Если завершить нельзя, обычный мастер не предлагается, пока процесс жив; пользователь видит понятное сообщение
- [ ] Перед запуском установщика открытая камера закрывается (или текст «камера будет отключена» убран, но лучше закрыть), после установки — переподключение
- [ ] Гонка «диалог прогресса показан после завершения установки» исключена: прогресс не может остаться на экране без кнопок
- [ ] Тест на отмену через CancellationToken → Cancelled

**Сохранение (`CapturePanelViewModel`, `GalleryViewModel`, `Export/`)**
- [ ] Старый цикл тайм-лапса после остановки не пишет в общее состояние новой серии (проверка «мой cts всё ещё текущий»)
- [ ] «Удалить» в ленте удаляет и `_clean`, и `.json`; текст подтверждения говорит об этом
- [ ] `FrameExporter` и декодер миниатюр освобождаются при закрытии окна (после WaitIdle); тесты освобождают созданные экспортёры
- [ ] Пока при закрытии окна дописываются снимки, это видно (например заголовок/Notify «Дописываю снимки…»)

**Линейка (`Views/PreviewOverlay.xaml.cs`)**
