## Что должно заработать

Поверх изображения рисуется плашка масштаба с «круглой» длиной и подписью в мкм или мм.
Её вид настраивается (угол, цвет, подложка, шрифт, толщина, ручная длина), а саму плашку
можно перетащить мышью. Масштаб берётся из профиля текущего объектива. Объектив калибруется
по объект-микрометру: провести линию, ввести известную длину, получить мкм/пиксель. Без
калибровки плашка выключена и показана подсказка: масштаб не врёт. Режим «Линейка» измеряет
отрезки, есть перекрестие и сетка. Рисование сделано одним кодом (`OverlayRenderer`), чтобы
таск 06 впечатывал в файл ровно то же самое.

## Критерии приёмки

- [ ] `ScaleBarMath.Choose`: длина из ряда 1-2-5×10ⁿ мкм, ближайшая к `targetFraction·frameWidth`; при `fixedMicrons` — она. `FormatLength`: < 1000 мкм → «N мкм», иначе «N мм» (до 2 знаков после точки, без хвостовых нулей). Тесты на несколько масштабов
- [ ] `Calibration.MicronsPerPixel` (тест), `MeasurementText.Label` (мкм или мм при калибровке, «N px» без неё; тест)
- [ ] `OverlayState` (запись) содержит всё для рисования: настройки плашки, мкм/px (nullable), измерения, линия калибровки в процессе, перекрестие, сетка. `OverlayRenderer.Draw(dc, state, frameSize, scale)` рисует плашку (линия + подпись + подложка α 0.55, радиус 6), измерения (линия с засечками и подписью), перекрестие, сетку (α 0.35). `scale` масштабирует шрифт и толщины. Форма `OverlayState` и способ получить текущее состояние для экспорта (например `ScalePanelViewModel.BuildOverlayState()`) записаны в `interfaces.md` → «Что построено»: по ним работает таск 06
- [ ] `PreviewOverlay` рисует `OverlayRenderer` в координатах кадра. Шрифт и толщины на экране не зависят от зума (scale = 1/текущий зум превью). Перетаскивание плашки → `ScaleBar.CustomX/Y`; «Вернуть в угол»
- [ ] Карточка «Масштаб»: выбор объектива, «Добавить объектив» (имя), переименовать, удалить (последний удалить нельзя), «Калибровать» (ActiveTool=Calibrate: клик-клик → диалог «Известная длина, мкм» → мкм/px в профиль, Notify), показ «X.XXX мкм/px» или «не откалиброван — откалибруйте объектив». Переключатель плашки (неактивен без калибровки, с пояснением), угол, цвет, подложка, шрифт 10–48, толщина 2–12, длина «Авто»/вручную, единицы
- [ ] Карточка «Измерения»: «Линейка» (ActiveTool=Ruler; клик-клик — отрезок; Esc — выход), список измерений с длинами и удалением, «Очистить всё», «Перекрестие», «Сетка» + шаг (мкм при калибровке, % без неё)
