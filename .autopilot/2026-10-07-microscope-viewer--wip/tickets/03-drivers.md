## Что должно заработать

Если на компьютере нет драйверов камеры, программа при запуске сама говорит об этом и
предлагает поставить их из своей папки `Drivers\`. После «Установить» запускается
комплектный установщик INFINITY ANALYZE/CAPTURE с правами администратора: сначала тихо, с
прогрессом в окне, при неудаче — обычным мастером. После установки камера подключается без
перезапуска. В интернет программа не ходит. Плюс `publish.ps1`, который собирает готовую
папку для переноса на компьютер с микроскопом, и обновлённая документация, включая раздел
«Окружение разработчика».

## Критерии приёмки

- [ ] `DriverService` по контракту: `IsInstalled` = `CameraFactory.IsDriverAvailable()`; `FindBundledInstaller` — первый `*.exe` в `DriversFolder` (по алфавиту), null, если папки или файла нет (тесты с временной папкой); `InstallAsync(silent)`: `runas`, тихие аргументы `/S /v"/qn REBOOT=ReallySuppress"`, таймаут 10 мин, коды 0 → Success, 3010 → SuccessRebootRequired, Win32Exception 1223 → Cancelled, иначе Failed; после завершения повторная проверка `IsInstalled` (Success, но DLL не грузится → Failed)
- [ ] `DriverStartupFlow.EnsureDriversAsync(host)`: драйвер есть → true без диалогов. Нет → WPF-UI `ContentDialog` (или стилизованное окно) «Драйверы камеры не найдены» с кнопками «Установить» / «Демо-режим» / «Позже» и текстом, что установка идёт из комплекта программы без интернета. «Установить» → прогресс (ProgressRing, «Устанавливаю драйверы… это может занять несколько минут») → результат. Тихая установка не удалась → вопрос «Запустить обычный мастер установки?». 3010 → `Notify` «Рекомендуется перезагрузка». Установщика нет → текст из истории 7 и кнопка «Открыть папку» (создаёт `Drivers\`, если её нет). «Демо-режим» → `host.StartDemo()` и false. «Позже» → false. Если `Settings.Camera.PreferDemo` — диалог не показывается
- [ ] `ReinstallAsync(host)` — тот же поток установки с подтверждением «Переустановить драйверы из комплекта?»; после успеха — `host.ConnectAsync()`
- [ ] csproj: `installer\infinity*.exe` копируется в `Drivers\` вывода и publish (`Link`, `CopyToOutputDirectory=PreserveNewest`, `CopyToPublishDirectory=PreserveNewest`, `ExcludeFromSingleFile=true`). Проверка: после `dotnet build` в `bin\...\Drivers\` лежит установщик. Сборка не падает, если установщика нет (условие `Exists` или шаблон)
- [ ] `publish.ps1` в корне: self-contained single-file win-x64 Release → `dist\LumeneraViewer\` (exe + `Drivers\` + `README.txt`), понятный вывод, ошибка, если нет установщика в `installer\`. Запустить и убедиться, что папка собралась и exe запускается. `dist/` добавить в `.gitignore`
