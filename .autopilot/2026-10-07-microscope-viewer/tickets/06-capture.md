## Что должно заработать

Кнопка «Снимок» и Пробел сохраняют текущий кадр в полном разрешении, с той же коррекцией,
что на экране, и, если включено, со впечатанными плашкой и измерениями. Форматы: PNG,
JPEG с качеством, TIFF без сжатия или LZW, BMP, JPEG XR. Папка, префикс, понятное имя
файла, метаданные в `.json` рядом. Тайм-лапс снимает серию с интервалом. Лента внизу
показывает последние снимки: клик открывает файл, контекстное меню — «Показать в папке» и
«Удалить». Ошибка записи понятна, кадр не теряется.

## Критерии приёмки

- [ ] `FrameExporter.BuildFileName`: `{prefix}_{yyyyMMdd_HHmmss_fff}[_{objective}][_{0001}].{ext}`, недопустимые символы имени заменяются на `_` (тест). `Extension` (тест)
- [ ] `SaveAsync`: берёт обработанный кадр, при `BurnOverlays` и наличии оверлеев впечатывает их через `OverlayRenderer.Draw(..., scale = frameWidth/1600)` в `DrawingVisual` → `RenderTargetBitmap` (96 dpi, полный размер). Энкодеры: Png, Jpeg(QualityLevel), Tiff(None/Lzw), Bmp, Wmp. Запись во временный файл → `File.Move(overwrite)`. `AlsoSaveClean` → копия `_clean` без оверлеев. `WriteMetadata` → `<имя>.json` (время, модель/серийный, экспозиция, усиление, `ImageAdjustments`, объектив, мкм/px, размеры, формат). Работает в фоне, UI не замерзает. Тесты: сохранение каждого формата во временную папку (файл есть, декодируется, размеры верны), JSON пишется
- [ ] Карточка «Сохранение»: формат (качество JPEG 50–100 и LZW для TIFF видны только для своего формата), папка + «Обзор» + «Открыть папку», префикс, переключатели «Впечатывать оверлеи», «Сохранять также без оверлеев», «Метаданные .json». Всё в `Settings.Export`
- [ ] `CaptureCommand` (кнопка «Снимок» и Пробел): нет кадра → Notify «Нет кадра для сохранения»; успех → Notify Success с именем файла; ошибка (нет доступа или места) → Notify Error с текстом, кадр не теряется (в паузе повторное нажатие сохраняет тот же кадр). Повторные нажатия во время записи не теряются и не портят файлы
- [ ] Тайм-лапс: интервал (с, ≥ 0.5), количество (0 = ∞), Старт/Стоп, прогресс «N / M» и время до следующего кадра; файлы с номером серии; ошибка записи останавливает серию с сообщением; закрытие окна останавливает серию
- [ ] Лента: последние 30 файлов текущей папки экспорта (только поддерживаемые форматы), миниатюры декодируются в фоне с `DecodePixelWidth≈160`, новый снимок появляется слева с анимацией; клик → открыть файл; контекстное меню «Показать в папке», «Удалить» (с подтверждением, удаляет и `.json`). Пустая лента → подсказка «Снимков пока нет — нажмите Пробел»
- [ ] Никаких правок в `MainViewModel`/`MainWindow` (если нужно — `BLOCKED`)
- [ ] `dotnet build`/`dotnet test` зелёные. Ручная проверка в демо-режиме: снимок в каждом формате с плашкой. Скриншот с лентой — `.autopilot/2026-10-07-microscope-viewer--wip/screens/06-capture.png`
