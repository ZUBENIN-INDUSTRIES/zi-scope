# 0004. Драйверы из комплекта: runas, сначала тихий режим, потом мастер

## Контекст

Программа должна ставиться на любой компьютер без поиска драйверов в интернете. Пользователь положил локально проприетарный установщик INFINITY ANALYZE/CAPTURE v6.5.6 (InstallShield, 39 МБ).

## Решение

Наличие драйверов проверяется через `NativeLibrary.TryLoad("lucamapi.dll")` до первого P/Invoke. Установщик — первый `*.exe` в папке `Drivers\` рядом с exe. Он запускается через `Verb="runas"`, сначала в тихом режиме (`/S /v"/qn REBOOT=ReallySuppress"`, таймаут 10 мин). Если код возврата не 0 и не 3010 или DLL всё ещё не грузится, программа предлагает обычный мастер. Установщик не хранится в git (`installer/*.exe` в `.gitignore`); csproj и `publish.ps1` копируют его в `Drivers\` при сборке. В сеть программа не обращается нигде.

## Почему

- Отвергнуто: скачивать драйвер с сайта Lumenera. Это запрещено брифом и не работает на офлайн-машине у микроскопа.
- Отвергнуто: хранить установщик в git. 39 МБ бинарника навсегда раздуют историю, а право распространять проприетарный файл неясно.
- Отвергнуто: сразу показывать мастер. Это лишние шаги для оператора. Отвергнуто и обратное — только тихий режим: при сбое у пользователя не остаётся пути дальше. Поэтому сначала тихая установка, а при сбое — мастер.
- Отвергнуто: проверять, есть ли файл DLL на диске. `TryLoad` проверяет то, что действительно важно (библиотека загружается), и позволяет подключить камеру без перезапуска программы.

## Последствия

- Из свежего клона полный комплект не собрать: установщик нужно вручную положить в `installer\`. Без него сборка проходит, но папка `Drivers\` пустая, и программа подсказывает пользователю, куда положить файл.
- Аргументы тихого режима рассчитаны на InstallShield. Установщик другого типа не пройдёт тихий режим и уйдёт в ветку с мастером.
- Нужны права администратора (UAC). Отмену запроса (код 1223) программа обрабатывает отдельно.
- При коде 3010 программа только советует перезагрузить компьютер, но сама не перезагружает. До перезагрузки драйвер может работать не полностью.
