# 0014. Установка встроена в сам exe, без MSI и Inno Setup

## Контекст

Пользователь хочет, чтобы программа «нативно устанавливалась» на компьютер: появлялась в меню «Пуск»
и удалялась через «Приложения» Windows. Сейчас программа — один self-contained `ZI-scope.exe`.
На машине сборки нет ни Inno Setup, ни WiX. Новые NuGet-пакеты и инструменты без согласия пользователя
не добавляются.

## Решение

Установщиком служит сам `ZI-scope.exe`:
- Опубликованный exe, запущенный не из папки установки, предлагает «Установить».
- При установке он копирует себя в `%LocalAppData%\Programs\ZI-scope`.
- Создаёт ярлыки в «Пуске» и на рабочем столе через `WScript.Shell`.
- Пишет запись `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\ZI-scope`.
- Затем запускает установленную копию и закрывается.

Удаление — `ZI-scope.exe --uninstall`: убирает ярлыки и запись, а папку стирает скрытый .cmd после выхода процесса.
Новая версия, запущенная поверх старой, предлагает «Обновить».

## Почему

- Отвергнуто: Inno Setup или WiX. Нужен внешний инструмент сборки, которого нет, и второй артефакт для раздачи (setup.exe рядом с exe).
- Отвергнуто: MSIX. Нужна подпись сертификатом, а без неё пакет не ставится.
- Отвергнуто: установка в Program Files. Нужны права администратора, а лаборант часто их не имеет. Профиль пользователя
  (`%LocalAppData%\Programs`) — стандартное место для таких установок, как у VS Code и GitHub Desktop.

## Последствия

- Один файл и для «запустить», и для «установить». Если пользователь не хочет устанавливать, программа работает без установки.
- Установка для каждого пользователя Windows отдельная.
- Обновление заменяет exe, поэтому установленная копия в этот момент должна быть закрыта. Иначе будет понятная ошибка, а прежняя копия останется.
- exe не подписан, поэтому SmartScreen предупреждает при первом запуске скачанного файла.
