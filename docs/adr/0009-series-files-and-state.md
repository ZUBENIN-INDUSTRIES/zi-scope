# 0009. Серия: отдельный файл на каждый вид кадра по шаблону имени, состояние в папке серии

## Контекст

Пользователь называет файлы как `группа_образец_увеличение_вид` (`1_1_100_1` — без масштаба, `1_1_100_2` — с масштабом). Серия на 128 шагов не укладывается в один сеанс. Обычный снимок сохраняет файл с оверлеем, его копию `_clean` и при совпадении имён добавляет суффиксы.

## Решение

Каждый вид кадра — отдельный файл. Имя строится по шаблону `{group}_{sample}_{mag}_{kind}`, без автосуффиксов и без копии `_clean`. Номер вида берётся из расширяемого списка `FrameKind {номер, название, оформление}`. Оформление (`Clean`, `ScaleBar`, `ScaleBarAndMeasurements`) решает, какие оверлеи впечатать. Существующий файл перезаписывается только при пересъёмке или после подтверждения. План, статусы шагов и список файлов хранятся в `<папка серии>\series.zscope-series.json` и обновляются после каждого шага. При открытии шаги, чьих файлов нет на диске, снова становятся «не снят».

## Почему

- Отвергнуто: использовать для серии обычную пару «файл + `_clean`». Имена `_clean` и `_2` не совпадают со схемой пользователя, а виды 3, 4, 5 «с измерениями» в пару не укладываются.
- Отвергнуто: суффиксы при совпадении имени, как в обычном снимке. Это тихо создало бы `1_1_100_1_2.png` рядом с правильным файлом, и в папке оказались бы дубли. Пересъёмка должна заменять файл.
- Отвергнуто: хранить состояние серии в `settings.json`. Серия привязана к своей папке: её можно перенести на другой диск или открыть на другом компьютере вместе со снимками, а настройки программы от этого не разрастаются.

## Последствия

- Шаблон имени — контракт с пользователем и его скриптами обработки. Если поменять умолчание или правила замены символов, старые и новые серии будут называться по-разному.
- Формат `series.zscope-series.json` нужно держать обратно совместимым, иначе незаконченные серии не откроются.
- Файлы, удалённые или переименованные вручную в проводнике, программа увидит только при следующем открытии серии.
- Без `_clean` чистый кадр есть только тогда, когда в списке видов есть вид «Чистый».
