# 0010. Сетка и перекрестие только на экране, в файл не впечатываются

## Контекст

Оверлей рисуется одним кодом и на превью, и в файле: в файл попадало всё, что видно на экране, включая сетку и перекрестие. Пользователь включает их для наводки, но на снимках они ему не нужны.

## Решение

Сетка и перекрестие рисуются только на превью. В файл они не попадают ни при обычном снимке, ни в тайм-лапсе, ни в серии. Плашка масштаба и линии измерений впечатываются, как раньше. Отдельного переключателя «впечатывать сетку» нет.

## Почему

- Отвергнуто: флажок «впечатывать сетку и перекрестие» в настройках экспорта. Пользователь сформулировал правило без исключений, а лишний флажок, включённый по ошибке, испортил бы серию из сотни кадров.
- Отвергнуто: убирать сетку только в серии. Тогда обычный снимок и снимок серии с одинаковыми настройками выглядели бы по-разному.
- Отвергнуто: отдельный экранный слой вместо общего `OverlayRenderer`. Один рисовальщик остаётся, в экспорт просто идёт состояние без сетки и перекрестия. Так плашка на экране и в файле по-прежнему совпадает.

## Последствия

- Экран и файл больше не совпадают один к одному, хотя ADR 0003 и R10.3 этого требовали. Это осознанное исключение только для сетки и перекрестия.
- Если сетка понадобится на снимке, например для подсчёта по клеткам, её не получить без изменения кода.
- Новый «экранный» элемент оверлея нужно явно исключать из состояния для экспорта, иначе он попадёт в файл.
