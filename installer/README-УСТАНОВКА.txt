УСТАНОВКА ZI-scope НА КОМПЬЮТЕР С МИКРОСКОПОМ (камера Lumenera INFINITY 4)
==========================================================================

Что нужно
---------
  ZI-scope.exe         — вся программа в одном файле. Внутри уже есть .NET
                         и установщик драйверов камеры INFINITY ANALYZE/CAPTURE
                         (Teledyne Lumenera): ничего ставить и скачивать
                         заранее не нужно.
  README.txt           — этот файл (для работы не нужен).

Нужна Windows 10 (версия 2004 или новее) или Windows 11, 64-бит.
Интернет для установки и работы не нужен. Программа в сеть не ходит.


ШАГ 1. Скопировать программу
----------------------------
Скопируйте ZI-scope.exe в любое удобное место, например в C:\ZI-scope
или на Рабочий стол. Ярлык на Рабочий стол: правой кнопкой по файлу →
«Показать дополнительные параметры» → «Отправить» → «Рабочий стол (создать ярлык)».

Если при первом запуске Windows покажет синее окно «Система Windows защитила
ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае». Так бывает
с любой программой без цифровой подписи; спросит только один раз.


ШАГ 2. Запустить программу
--------------------------
Запустите ZI-scope.exe. Первый запуск может занять 5–10 секунд — программа
распаковывает себя; дальше открывается быстрее.

Если драйверов камеры на компьютере ещё нет, программа сама покажет окно
«Драйверы камеры не найдены» с кнопками:
  «Установить»  — запустить установщик драйверов, вшитый в программу (он
                  распакуется в %LocalAppData%\ZI-scope\Drivers). Windows
                  спросит права администратора (UAC) — ответьте «Да». Установка
                  идёт в тихом режиме, в окне программы крутится индикатор;
                  обычно это занимает несколько минут.
                  Если тихая установка не удастся, программа предложит запустить
                  обычный мастер установки — пройдите его шаги (Далее → Далее →
                  Готово).
                  После установки камера подключится сама, перезапускать
                  программу не нужно. Если установщик попросит перезагрузку,
                  программа покажет уведомление — перезагрузитесь, когда будет
                  удобно.
  «Демо-режим»  — попробовать программу без камеры (симулятор препарата).
  «Позже»       — продолжить без драйверов.

Установить или переустановить драйверы можно в любой момент: меню «⋯» в правом
верхнем углу → «Установить/переустановить драйверы».


ШАГ 3. Подключить камеру
------------------------
1. Подключите Lumenera INFINITY 4 по USB (лучше в порт USB 3.0, синий разъём —
   для полной скорости и разрешения).
2. Подождите несколько секунд, пока Windows определит устройство. Программа
   сама найдёт камеру; если нет — нажмите «Повторить».


Если что-то не так
------------------
  • Перепутаны красный и синий цвета, или картинка «шумная» — меню «⋯» →
    «Дополнительно»: «Поменять местами R и B», метод дебайеринга.
  • Камера не находится — проверьте кабель и питание, переподключите камеру,
    нажмите «Повторить». Если драйверы ставились только что и установщик
    просил перезагрузку — перезагрузите компьютер.
  • Настройки программы лежат в %AppData%\ZI-scope\settings.json
    (при первом запуске туда копируются настройки прежней версии
    из %AppData%\LumeneraViewer\).
    Сбросить их можно в меню «⋯» → «Дополнительно».
